# Aula 08-09 — Métodos HTTP

## 📌 Sobre a atividade

Nesta aula foi desenvolvido um projeto utilizando **NestJS** para praticar os principais métodos HTTP de uma **API REST**, utilizando o gerenciamento de convidados.

## 🎯 Objetivo

Praticar as operações de:

* **GET** — consultar convidados
* **POST** — cadastrar convidados
* **PATCH** — atualizar convidados
* **DELETE** — excluir convidados

## 🛠️ Tecnologias utilizadas

* Node.js
* NestJS
* TypeScript

## 👥 Gerenciamento de convidados

A API permite realizar operações de **CRUD** sobre os convidados cadastrados, utilizando diferentes métodos HTTP.

## 📖 Aprendizado

Com esta atividade, foi possível aprender como criar **rotas no NestJS** e utilizar os métodos **GET, POST, PATCH e DELETE** para consultar, cadastrar, atualizar e excluir dados.
